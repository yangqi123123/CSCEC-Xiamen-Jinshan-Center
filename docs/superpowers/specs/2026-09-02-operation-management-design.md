# 运营管理大屏设计

## 目标

在 `Big Screen/index.html` 中新增顶部“运营管理”模块，保持现有大屏的深蓝 HUD 视觉语言、中央建筑、楼层选择和平面图交互不变。

## 交互

- 点击顶部“运营管理”后，中央建筑继续显示，底部显示两个椭圆按钮：“资产管理”和“运营管理”。
- 首次进入运营管理默认选中“资产管理”。
- 点击“资产管理”切换左右看板：左侧显示“资产总量”“维保计划”，右侧显示“固定资产”“可移动资产”“故障报警”。
- 点击“运营管理”切换左右看板：左侧显示“租赁统计”“楼层租赁明细”，右侧显示“报事报修”“工单消息”“投诉建议”。
- 离开运营管理时清理运营状态类，恢复总览、机电、弱电和能源模块原有显示逻辑。

## 布局与视觉

- 复用现有 `.workspace`、`.left-rail`、`.right-rail` 和 `.building-scene` 容器，不新增页面或构建依赖。
- 运营看板使用现有 `.info-panel`、`.panel-title`、青色描边、蓝色半透明底和黄色选中态。
- 运营底部按钮沿用现有系统底部椭圆按钮规格，固定在中央建筑区域下方，不覆盖按钮内容或主体建筑。
- 看板使用固定网格行高和 `overflow: hidden`，避免切换时改变工作区尺寸或出现底部溢出。
- 数据为静态原型数据，租赁楼层采用双列明细，报修/工单/投诉采用参考图中的计数、进度和消息列表结构。

## 实现边界

- 只修改 `Big Screen/index.html`，不更改中央建筑图片、平面图资源及既有楼层和设备点位逻辑。
- 运营状态与能源、机电、弱电状态互斥，切换时清除旧状态，避免旧 CSS 选择器影响新面板。
- 新增按钮提供 `type="button"` 和可识别的可访问名称；切换只更新原型界面状态，不接入后端。

## 验收

- 点击顶部“运营管理”后可看到两个底部按钮，默认显示资产管理。
- 两个底部按钮均可切换到对应的左右看板，文字和模块数量完整可见。
- 从总览、机电、弱电、能源管理任意模块切换到运营管理，工作区不变形，中央建筑、楼层按钮和平面图资源不受影响。
- JavaScript 语法检查通过，页面在 1920x1080 固定设计基准下无新增滚动或按钮裁切。
