# 弱电系统三类看板补齐设计

## 目标

修复 `Big Screen/weak-electric.html` 中“智慧停车”“综合安防”“信息网络”切换后左右看板内容缺失的问题，并依据用户提供的三张参考图补齐对应业务数据。中央建筑、顶部导航、底部圆形导航和现有楼层交互保持不变。

## 页面结构

- 三类场景继续复用现有 `.mep-left` 和 `.mep-right` 两个看板栏位。
- 每个场景的面板直接放入所属栏位，通过 `parking-active`、`security-active`、`network-active` 状态类切换显示。
- 不再使用依赖文档顺序的 `nth-of-type` 绝对定位，也不在切换时隐藏承载面板的左右栏位。

## 智慧停车

- 左栏：停车概览、剩余车位、AGV 车位、充电桩。
- 右栏：负一层入口/出口视频、停车场六宫格视频。
- 使用参考图中的数据：西侧入场 120、西侧离场 135、南侧入场 95、南侧离场 120、占用率 2%、B1/B2/B3 剩余车位 54/145/134、AGV 车位 22、充电桩 43。

## 综合安防

- 左栏：道闸系统、门禁系统，展示设备数、故障率、在线/离线和联动记录。
- 右栏：监控系统、系统告警/联动记录、关键区域监控。
- 使用参考图中的核心数据：道闸设备 6、门禁设备 198、监控设备 416，故障率均为 0%。

## 信息网络

- 左栏：数据中心机房、消控室、弱电井，包含环境/设备概览、在线状态及设备列表。
- 右栏：信息网络分类、设备运行状态、系统报警。
- 使用参考图中的核心数据：防火墙 1、交换机 35、WAC 0，在线 36、离线 0、报警 0。

## 视觉与交互

- 复用当前深蓝、青色描边、低圆角的数字孪生大屏视觉，不引入新的设计体系。
- 面板信息保持高密度但可扫描，正常状态使用绿色，故障与报警使用红色/橙色。
- 底部五个弱电子系统按钮继续通过现有 `renderSystem` 切换状态，新增面板不改变既有事件绑定。
- 面板内部按钮和 tabs 保留可见的悬停及焦点状态。

## 验收标准

- 点击“智慧停车”“综合安防”“信息网络”后，左右两侧均显示对应看板，不再出现空栏。
- 三个场景内容层级、标题和主要数值与参考图一致。
- 1920×1080 基准画布无面板重叠、溢出或底部导航遮挡。
- “系统总览”和“会议办公”原有页面不回归。
- 控制台无 JavaScript 错误，三个场景可连续往返切换。
