# 运营管理弹窗统一设计

## 目标

将运营管理页面的维保记录、固定资产、可移动资产与资产详情弹窗统一为机电系统“设备详情”的深色切角面板风格，并补充资产详情中的保养字段。

## 范围

- 仅修改 `Big Screen/operation.html` 所使用的运营管理弹窗样式及其现有静态 Mock 数据呈现。
- 不调整顶部导航、底部按钮、中间建筑、平面图或其他业务模块。

## 视觉与布局

- 四类弹窗均居中显示，使用与设备详情一致的深蓝渐变底色、青色描边、切角轮廓、顶部斜纹装饰、标题栏和右上角关闭按钮。
- 维保记录、固定资产、可移动资产列表弹窗使用固定的中等宽高，避免全屏铺开。
- 资产详情弹窗使用较窄的纵向面板；字段采用三列网格，标签和值在各自字段内左对齐。
- 列表的表头、字段名称和值默认左对齐；序号和操作区域沿用紧凑列宽，但其文字也不因居中而偏离统一阅读基线。

## 资产详情字段

在“保养到期时间”之后，依次展示：

1. 保养说明
2. 预计折旧期限（月）
3. 标签链接
4. 图片

其中“保养说明”和“图片”占满一整行，“预计折旧期限（月）”与“标签链接”按普通字段网格排列。全部使用静态 Mock 值。

## 验收标准

- 打开任一目标弹窗时，边框、标题和关闭按钮与机电系统设备详情弹窗具有一致的视觉语言。
- 四类弹窗不再以近全屏方式显示。
- 维保记录、固定资产、可移动资产的列表字段和资产详情字段均左对齐。
- 资产详情中“保养到期时间”紧接四个指定字段，字段顺序正确，且内容未溢出。
- 页面脚本语法有效，修改文件不存在乱码替换字符。
