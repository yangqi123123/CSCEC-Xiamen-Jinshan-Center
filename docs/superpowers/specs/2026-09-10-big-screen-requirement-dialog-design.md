# 大屏需求说明悬浮组件设计

## 目标

在五个大屏业务页面提供统一的“需求说明”入口。入口固定在浏览器视口左下角，点击后展示与现有大屏一致的深蓝科技风弹窗；各页面的文档内容直接写在对应 HTML 中，便于后续独立维护。

## 结构

- `Big Screen/requirement.js` 负责创建悬浮按钮、Tooltip、遮罩和弹窗，并读取当前页面的 `#requirementDocument` 模板。
- `Big Screen/styles.css` 负责组件的固定定位、弹窗视觉、滚动区域及响应式约束。
- 五个业务 HTML 页面使用统一的 `<template id="requirementDocument">` 结构维护本页需求说明。
- 模板章节统一使用 `data-requirement-section` 标识。脚本会删除无正文、无有效列表项或无有效数据行的章节，避免出现空白区域。

## 交互

悬浮按钮位于 `left: 24px; bottom: 24px`，不受大屏缩放与内容滚动影响。鼠标悬浮或键盘聚焦时，在按钮右上方展示白色“需求说明”Tooltip。点击按钮打开弹窗；点击遮罩、右上角关闭按钮或按 `Esc` 均可关闭，并在关闭后将焦点归还给入口按钮。

## 视觉

按钮使用蓝色圆形、白色书本图标和柔和青蓝外发光。弹窗复用现有大屏的青色描边、深蓝渐变、切角轮廓和轻发光，内容区采用高对比白色正文、青色章节标题与可横向滚动的数据表。

## 验收

五个业务页面均显示同一位置的入口；Tooltip、打开和三种关闭方式有效；页面模板可直接编辑；空章节不出现在弹窗中；在常见桌面与窄屏视口内无溢出或遮挡。
