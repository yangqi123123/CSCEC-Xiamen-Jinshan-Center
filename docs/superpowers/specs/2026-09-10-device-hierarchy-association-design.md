# 设备层级与下游设备关联设计

## 目标

将设备管理中的“是否附属设备”统一调整为“设备层级”，用“主设备 / 下游设备”表达两级设备关系。主设备可关联已有下游设备，下游设备只能归属于一个主设备。

## 字段与数据模型

- 原字段 `attachment` 继续作为原型内部字段使用，展示名称统一改为“设备层级”。
- 字段选项仅允许“主设备”和“下游设备”，默认值为“主设备”。
- 每台下游设备增加 `parentDeviceId`，保存所属主设备 ID；未关联时为空。
- 设备编辑为“主设备”时清空其 `parentDeviceId`。
- 已关联下游设备的主设备不允许直接改为“下游设备”，需先解除全部下游设备关联。

## 页面调整

列表筛选、列表列名、新增、编辑、详情、导入、导出和下载模板中的“是否附属设备”统一改为“设备层级”，选项和导入值为“主设备 / 下游设备”。

主设备详情保留三个页签：“设备信息 / 下游设备 / 文件资料”。下游设备页签展示已关联设备，操作列仅显示“详情、解除关联”。“详情”打开独立下游设备详情抽屉；“解除关联”只清空关联关系，不删除设备台账。

下游设备详情隐藏“下游设备”页签，只显示“设备信息 / 文件资料”。设备信息增加“所属主设备”，已关联时显示主设备名称和编码，未关联时显示“-”。

## 关联流程

主设备详情的“下游设备”页签中，点击“新增”打开设备选择弹窗。候选设备必须同时满足：

1. 设备层级为“下游设备”。
2. `parentDeviceId` 为空，即尚未关联其他主设备。
3. 与当前主设备所属系统相同，或设备分类相同。
4. 不是当前主设备本身。

弹窗支持多选。确认后将所选设备的 `parentDeviceId` 设置为当前主设备 ID，并刷新下游设备列表。若没有符合条件的设备，展示空状态。

## 导入导出

- 模板表头“是否附属设备”替换为“设备层级”。
- 模板示例值使用“主设备”。
- 导入仅接受“主设备”或“下游设备”，其他值作为校验失败数据处理。
- 本次不通过导入文件建立上下级关联；导入的下游设备默认处于未关联状态。
- 导出“设备层级”当前值，不额外增加所属主设备列。

## 交互与异常规则

- 一个下游设备只能关联一个主设备。
- “解除关联”需二次确认，确认后仅清空 `parentDeviceId`。
- 删除主设备前若存在下游设备，先提示解除关联；本次原型中阻止直接删除。
- 删除已关联的下游设备时，沿用设备删除确认，删除后关联自然失效。
- 关联、解除关联和编辑后只刷新受影响列表，不关闭主设备详情抽屉。

## 验证

- 检查所有页面文案和 Excel 表头不再出现“是否附属设备 / 附属设备”。
- 验证主设备显示下游设备页签，下游设备隐藏该页签并显示所属主设备。
- 验证候选列表过滤、唯一归属、多选关联和解除关联。
- 验证新增、编辑、详情、导入、导出及模板字段值一致。
- 执行页面内联 JavaScript 语法检查，并确认页面可正常访问。
