# 设备管理页面优化设计

## 目标

在不改变现有设备管理列表、详情页和公共后台风格的前提下，完善二维码下载、设备录入联动、房源级联、平面图打点及 Excel 导入导出能力。页面继续使用 Mock 数据，不接入后端接口。

## 页面与依赖

- 目标页面：`web/pages/device/list.html`
- 系统类型数据：`app/data/system-types.js`
- 设备分类数据：与 `web/pages/device/category.html` 中的 Mock 分类保持一致
- 平面图资源：将用户提供的图五复制到 `web/assets/images/`，页面不引用临时目录
- Excel：通过 SheetJS CDN 生成和解析 `.xlsx`
- 二维码：通过 QRCode CDN 生成真实二维码图片
- 多选二维码下载：通过 JSZip CDN 将多个 PNG 打包为 ZIP

## 列表工具栏与二维码

- “打印二维码”改为“下载二维码”。
- 未勾选设备时按钮禁用，勾选后启用。
- 单选时下载一张 PNG；文件名为“设备名称+设备编码.png”。
- 多选时生成 ZIP，压缩包内每台设备一张 PNG，命名规则相同。
- 二维码图片包含二维码、设备名称和设备编码；二维码内容使用设备名称和设备编码组成的文本。
- 操作列“二维码”打开居中弹窗，展示二维码、设备名称、设备编码，并提供下载按钮。

## 设备录入

- “设备编号”统一改为“设备编码”。
- “所属系统”改为树形下拉，读取系统类型 Mock 数据，支持展开、收起和路径回显。
- 未选择所属系统时“设备分类”禁用。
- 选择所属系统后，仅展示该系统对应的设备分类。
- “所属房间”改为“所属房源”，使用“楼栋 → 楼层 → 房源”三级级联选择，选中后显示完整路径。
- 服务范围和备注使用与其他表单项一致的 16px 间距。
- 删除字段：BIM关联EID、设备所属子系统、设备高度、目标坐标。
- “原始坐标”改为“设备坐标”。
- “是否智能化”为“否”时隐藏“设备所属物模型”和“第三方编码”；切回“是”时恢复显示。

## 点位选择

- 在点位信息下增加“点位选择”按钮。
- 点击后打开居中弹窗，左侧为楼栋与楼层选择，右侧显示二维平面图。
- 点击平面图生成点位标记；再次点击时移动标记。
- 使用点击点相对图片宽高的百分比生成坐标，确认后回填“设备坐标”。
- 切换楼层时保留当前表单上下文，点位以当前楼层为准。

## Excel 导入导出

- 原“导入/导出”拆分为“导入”和“导出”两个按钮。
- 导出将当前筛选结果生成 `.xlsx` 文件。
- 导入抽屉支持点击或拖拽上传 `.xlsx`、`.xls` 文件，并提供“下载模板”按钮。
- 模板为 `.xlsx`，表头包含新增设备表单的全部必填项：所属系统、设备分类、设备名称、设备编码、所属房源、安装位置、是否附属设备、是否智能化、设备所属物模型。
- 当“是否智能化”为“否”时，设备所属物模型允许为空；其他必填项为空的导入行不写入列表，并在页面反馈失败数量。
- 导入成功后将有效行加入当前 Mock 列表并刷新表格。

## 交互与异常处理

- 下载二维码按钮状态跟随列表勾选状态实时更新。
- 所属系统变化时清空原设备分类，避免系统与分类不匹配。
- Excel 文件格式错误、缺少必填表头或没有有效数据时，使用系统确认弹窗提示。
- 图片、二维码或 Excel 库加载失败时明确提示，不静默失败。
- 关闭弹窗或抽屉后清理临时文件、二维码画布和点位状态。

## 验证

- 检查未勾选时二维码下载按钮禁用，单选和多选下载文件命名正确。
- 检查二维码弹窗内容及 PNG 图片包含二维码、设备名称、设备编码。
- 检查系统树、设备分类联动、房源三级级联和智能化字段显隐。
- 检查不同楼层点位选择及设备坐标回填。
- 检查 `.xlsx` 模板下载、导出、有效导入和错误文件提示。
- 检查 JavaScript 语法、乱码、按钮尺寸、抽屉和弹窗在常用桌面宽度下无重叠。
