# App 移动端登录与首页原型设计

## 目标

优化 `app/app-login.html`，让它成为可直接演示的 iPhone 15 风格移动端原型：登录页使用账号/密码登录，固定测试凭据为 `13800002026` / `888888`；登录成功后在同一移动端画布内切换到移动端首页，不再跳转到 Web 后台。

## 设计方向

采用截图中的浅灰蓝工业管理风格：大面积 `#f5f7fc` 背景、白色内容区、品牌蓝作为主操作色，青绿/橙红仅用于状态语义。页面按 iPhone 15 的 CSS 逻辑视口比例设计（393 x 852 CSS px），桌面预览时显示真实比例手机外框；窄屏时外框缩放到可用宽度，内容始终使用安全区和垂直滚动。

中文字体栈以 `PingFang SC` 为首选，回退到 `Microsoft YaHei`、`Helvetica Neue` 和系统无衬线字体；正文不低于 14px，关键触控目标不低于 44px。图标继续使用现有 Font Awesome CDN，不使用 emoji 代替功能图标。

## 页面结构

1. 手机外框与状态栏：黑色 iPhone 外壳、顶部灵动岛、时间、信号、Wi-Fi、电量和底部 Home Indicator；安全区通过固定内边距体现。
2. 登录视图：品牌标识、标题“工业小程序”、账号输入框、密码输入框、密码可见性切换、固定凭据提示、登录按钮和错误提示。去掉扫码登录与企业微信授权文案。
3. 首页视图：顶部问候与通知入口；设备/工单/功能搜索框；工业管理平台蓝色横幅；数据概览四项指标；常用功能八项网格；告警信息列表；固定底部导航。
4. 其他底部导航状态：设备、工单、我的 tab 提供轻量简化视图和返回首页能力，避免点击后无反馈；首页为默认主视图。

## 交互与数据流

- 登录按钮读取账号和密码，只有完全匹配 `13800002026` 与 `888888` 才进入首页。
- 账号或密码为空时，在对应区域显示“请输入账号/密码”；凭据不匹配时显示“账号或密码错误，请检查后重试”。提交期间按钮显示加载状态并短暂禁用，完成后切换首页。
- 密码眼睛按钮切换 `type=password/text`，并提供 `aria-label`。
- 首页通知、搜索、常用功能、告警项和底部导航均为可点击控件，点击后以提示条或 tab 视图反馈，不引入真实后端请求。
- 使用 CSS class 控制 `login-view` 与 `home-view` 的显隐；所有数据以内联静态数据渲染，页面刷新回到登录态，避免伪造持久化登录。

## 视觉与响应式细节

- 页面外层桌面背景使用浅灰蓝和低对比度工业网格；手机屏幕内容保持纯净白色/浅灰色，避免大面积渐变。
- 卡片圆角控制在 8px 以内，阴影使用低透明度蓝灰色；主按钮为品牌蓝，告警使用红/橙并同时显示文字。
- 首页横幅使用远程 Unsplash 图片作为工业场景背景，叠加纯色半透明层保证文字对比度，并声明 `loading`、`width`、`height` 和 `alt`。
- 使用 8px 间距节奏和 44px 以上触控区域；底部导航固定在手机安全区内，不遮挡滚动内容。
- 使用 `prefers-reduced-motion` 降低切换和加载动画；不产生横向滚动。

## 验证

- 用 Node 检查页面内脚本语法，确认 `app-login.html` 不再包含 Web 后台跳转和扫码/企业微信文案。
- 用 Playwright 或本地浏览器在桌面、iPhone 15 CSS 视口和窄屏视口打开页面，验证登录成功/失败、密码显示、首页切换、底部导航和无横向滚动。
- 截取登录页和首页预览图，检查手机外框比例、中文字体回退、内容层级、底部安全区和横幅图片加载。
