# 总览左栏与车辆统计设计

## 目标

调整 `Big Screen/overview.html` 总览页左栏，使其稳定展示建筑概况、荣誉展示、人员统计、车辆统计四个模块，并让建筑概况最多可见四行，其余数据通过纵向滚动查看。

## 页面结构

- 左栏保持现有 360px 宽度和深蓝大屏视觉风格。
- 左栏自上而下为：建筑概况、荣誉展示、人员统计、车辆统计。
- 四个模块共享现有 `info-panel` 和 `panel-title` 组件，不改变中间建筑主体与右侧面板。
- 模块高度按内容密度分配，不强制等高：建筑概况固定为四行可视高度，车辆统计获得足够空间完整展示核心指标。

## 建筑概况

- 标题保持“建筑概况”。
- 内容区域高度精确容纳四行 `overview-row`。
- 第五行及之后通过内容区纵向滚动查看。
- 使用细窄青色滚动条，与设备列表等现有滚动区域一致。
- 不改变已有建筑字段和值。

## 车辆统计

- 移除总览左栏中分散的“停车概览”“AGV车位”“机械车位”卡片，合并为单个“车辆统计”模块。
- 顶部展示剩余车位汇总，使用醒目数字 `199/199`。
- 中部只展示 B1、B2 两个楼层车位，分别显示剩余数量与总数：B1 `54/54`，B2 `145/145`。
- 底部展示普通车位统计：普通车位 `22`、使用中 `0`、空余 `22`。
- 不展示 B3、机械车位或 AGV 车位文案。
- 图形使用现有 Font Awesome 图标、圆环、进度条和面板色彩，不引入新图片资源。

## 响应与兼容

- 页面继续使用现有 1920×1080 大屏缩放机制。
- 左栏四个模块总高度加间距不得超过工作区高度，不出现整栏滚动条。
- 建筑概况仅自身内容区滚动；荣誉、人员和车辆模块不出现内部滚动条。
- 保持已有人员统计周期切换、荣誉证书轮播和顶部公共操作不变。

## 验收标准

1. 默认视图左栏可同时看到四个模块标题及完整车辆统计模块。
2. 建筑概况默认最多展示四行，滚动后可看到其余字段。
3. 车辆统计包含 `199/199`、B1 `54/54`、B2 `145/145`、普通车位 `22`、使用中 `0`、空余 `22`。
4. 页面不再显示总览左栏的停车概览、AGV车位和机械车位独立模块。
5. 中间建筑主体和右侧面板的位置、尺寸和交互没有回归。

## 验证方式

- 对 HTML/CSS 运行 `git diff --check`。
- 在本地浏览器打开 `Big Screen/overview.html`，检查 1920×1080 视图。
- 滚动建筑概况内容区，验证第五行之后的数据可访问。
- 检查左栏无溢出、文字无重叠，车辆统计的所有数值完整显示。
