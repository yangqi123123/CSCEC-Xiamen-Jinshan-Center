# 四局厦门金山项目大屏参考图还原设计

## 目标

严格按照用户提供的参考图，重构 `Big Screen/index.html`。页面以 1920x1080 为唯一设计基准，在浏览器窗口内保持 16:9 等比缩放并居中展示。目标是还原参考图的构图、色彩、边框语言、信息密度和中文内容，同时保留可点击导航、实时钟表和底部控制按钮。

## 范围与约束

- 只修改 `Big Screen/index.html`，不改动其他页面或公共资源。
- 不新增图片、字体或构建依赖；使用原生 HTML、CSS、SVG 和 JavaScript。
- 中央建筑及园区使用分层 CSS/SVG 场景重建，左右信息区使用真实 HTML 数据模块。
- 图片中展示的中文与数值作为静态原型内容，不接入后端数据。
- 桌面端是本次唯一目标；小窗口允许整体按比例缩放，不增加移动端重排。

## 视觉与布局

### 画布

外层 `.viewport` 占满浏览器窗口，内层 `.screen-shell` 固定为 1920x1080，通过 `min(100vw / 1920, 100vh / 1080)` 等比缩放并居中。画布使用深海军蓝背景、局部径向光晕、网格纹理和四周 HUD 框线。

### 页面分区

- 顶部 96px：左侧项目名、时间、天气；中央系统标题；右侧单位标识和工具图标。
- 导航条约 54px：七个横向模块，当前“总览”使用琥珀色选中态，其余使用蓝色半透明底。
- 主体区域：左右信息栏各约 380px，中间为主要建筑场景。信息栏从主体顶部开始，采用透明蓝色面板和青色切角描边。
- 左栏依次为“建筑概况”“荣誉展示”“人员统计”“车辆统计”。
- 中央区域为建筑园区主视图，建筑位于视觉中心，背景包含水面、道路、树木和半透明体块；底部保留两个圆形悬浮控制按钮。
- 右栏依次为“能源管理”“环境指标”，能源模块包含四个仪表、趋势折线图和四个回收指标，环境模块包含分区 tabs 和六项环境数值。

### 视觉语言

主色使用深蓝、靛蓝、青蓝线条和亮青文字；黄色仅用于选中态和告警/能源强调，红色用于异常数值。面板采用低圆角或切角、内发光、细边框和细密装饰线。文字使用 `Microsoft YaHei` / `PingFang SC`，数字使用等宽或 DIN 风格字体。避免通用 SaaS 卡片样式与大面积紫色渐变。

## 组件与交互

- `.hud-header`：品牌、实时钟表、天气、系统标题、单位标识和工具按钮。
- `.module-nav`：七项主导航，点击后切换选中态；原型不切换页面内容。
- `.info-panel`：统一的切角面板、标题横线、双向箭头装饰和底部黄色角标。
- `.building-scene`：由背景光晕、河流、道路、树木、半透明建筑体块和中央写实感建筑层组成；使用 CSS/SVG 透视与低频扫描动画增强空间感。
- `.energy-panel`：四个圆形仪表、趋势图和回收/节能数据。
- `.environment-panel`：三个区域切换项和环境数据环绕布局。
- 时间每秒更新，日期格式为 `YYYY.MM.DD`；所有图标按钮提供 `aria-label` 与键盘 focus 状态。
- 装饰动画在 `prefers-reduced-motion: reduce` 下关闭；动画不得改变布局尺寸。

## 数据内容

左栏固定使用参考图中的“中建科创大厦”、建筑面积、开竣工日期、荣誉证书、办公人员 683、访客 0、低中高区人员、剩余车位 0、AGV/充电桩数量等内容。右栏固定使用参考图中的电耗、碳排、水耗、燃气、趋势图、光伏发电、电梯回馈、空气质量回收和节能减排数值。数据只用于视觉还原，不承诺实时业务准确性。

## 验收标准

- 在 1920x1080 窗口中，页面主体完整可见，无横向滚动，整体构图与参考图一致。
- 在 1366x768、2560x1440 窗口中，内层画布保持 16:9 等比缩放，不出现模块挤压、重排或文字覆盖。
- 中文无乱码；顶栏、导航、两侧面板、中央建筑和底部控制按钮均可见。
- 左右面板信息层级、颜色、边框、标题装饰和数字层级接近参考图，而非上一版设备运营仪表盘。
- 点击导航和底部控制按钮有可见状态变化；时钟持续刷新；键盘 focus 清晰。
- 页面无新增外部资源依赖导致的阻塞；静态 HTML 可直接在浏览器打开或通过本地静态服务器访问。
- 用浏览器截图检查 1920x1080、1366x768、2560x1440 三个视口，并检查控制台无脚本错误。
