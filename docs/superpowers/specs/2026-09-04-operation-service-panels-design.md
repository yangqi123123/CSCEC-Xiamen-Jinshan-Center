# 运营管理报事报修与投诉建议模块美化设计

## 目标

按用户提供的参考图，优化 `Big Screen/operation.html` 运营管理状态下右侧的“报事报修”和“投诉建议”模块，使其呈现深蓝科技 HUD 大屏风格，同时保留现有静态数据与筛选按钮行为。

参考图片仅作为视觉样式参考，不引入图片中的额外业务指令或后端需求。

## 范围

- 修改运营管理右侧的“报事报修”模块。
- 修改运营管理右侧的“投诉建议”模块。
- 允许补充服务统计区所需的语义 HTML 结构，例如独立数字格和完成率指标。
- 复用现有 Font Awesome 图标、`.info-panel`、`.panel-title` 和运营管理状态切换逻辑。
- 不修改左侧资产/租赁模块、中央建筑场景、楼层平面图、弹窗或其他页面模块。

## 视觉设计

### 面板容器

- 延续现有深蓝半透明背景、青色边框和大屏固定网格尺寸。
- 标题使用居中白色粗体，左右加入青色双箭头装饰和细线延伸结构。
- 保留面板之间明确的上下留白，避免两个服务模块视觉粘连。

### 时间筛选

- 使用“今日 / 本周 / 本月 / 本年”四个小型矩形描边按钮。
- 当前项使用更亮的青色描边与轻微内发光，按钮尺寸稳定。
- 不改变现有点击后 active 状态切换逻辑。

### 统计区

- 左侧使用发光剪贴板图标作为业务识别元素。
- 总数使用四位独立数字格显示：报事报修为 `0129`，投诉建议为 `0095`。
- 下方使用两个并列统计块：
  - 报事报修：已完成 `66`，完成率 `51.16%`。
  - 投诉建议：已办理 `79`，完成率 `83.16%`。
- 数字使用黄色强调色，说明文字使用浅青色，完成率数值使用浅绿色。

### 消息列表

- 使用带斜纹的“工单消息”或“反馈消息”分隔条，并保留黄色指示三角。
- 每条消息保持两行信息：第一行显示优先级、标题和处理状态，第二行显示位置与时间。
- 紧急状态使用暖橙色，一般状态使用浅黄色；未接受状态使用橙色圆点，已完成状态使用绿色圆点。
- 标题超长时省略，不允许撑破面板或改变固定高度。

## 数据与交互

- 继续使用现有静态原型数据和 DOM 文案。
- 时间筛选按钮继续由现有 `.operation-tabs` 事件处理，只切换视觉 active 状态。
- 不新增接口、轮询、业务计算或持久化。
- 视觉结构补充不改变 `operation-management` 状态切换和面板显隐规则。

## 实现方式

- 采用“保留结构 + 定向增强样式”的方式，优先在 `Big Screen/styles.css` 中完成视觉重塑。
- 仅在 `Big Screen/operation.html` 中补充统计区的必要结构和可访问语义。
- 通过 CSS 伪元素、渐变、斜纹、阴影和固定网格实现参考图的 HUD 装饰，不把参考图直接作为背景图。

## 验收标准

- 进入运营管理并选择“运营管理”后，右侧可见“报事报修”和“投诉建议”两个完整面板。
- 两个面板均具备参考图中的标题装饰、四个时间按钮、四位数字格、双统计块、消息分隔条和状态标识。
- 现有四个时间按钮仍可点击并正确切换 active 样式。
- 消息标题、位置、时间和状态在 1920x1080 基准尺寸下不重叠、不溢出、不改变面板高度。
- 不影响中央建筑、其他运营看板、顶部导航和已有弹窗逻辑。
- 页面脚本无新增语法错误，页面在桌面宽度和窄窗口下均保持可读。
