# Big Screen 1920×1080 视觉重构设计

## 目标

仅重构 `Big Screen/index.html`，将现有普通仪表盘页面升级为参考图风格的深色科技大屏，使用 1920×1080 作为电脑端视觉基准，并在不同电脑窗口尺寸下按比例自适应。手机端现有页面行为不在本次范围内，不新增移动端专用布局。

## 设计方向

采用参考图 3 的模块化数据墙作为主方向，融合参考图 1 的中心视觉聚焦和 HUD 边框语言：

- 主色为深海军蓝背景、冷蓝面板、青蓝高亮线，使用少量琥珀色表达预警。
- 页面采用低圆角、切角边框、斜向装饰线和柔和外发光，避免普通 SaaS 卡片的圆角堆叠感。
- 顶部使用居中的科技标题牌，左右分别放品牌标识、导航操作、时间和返回入口。
- 内容区固定为三列：左侧指标与告警，中部趋势与核心态势，右侧在线结构、区域排行和设备表。
- 所有中文文案统一为 UTF-8 正常显示，保留现有产品基座、设备、告警、工单和区域运营数据语义。

## 画布与自适应

- `.screen-shell` 作为 1920×1080 设计画布，内部尺寸始终以该基准组织。
- 外层 viewport 根据 `min(100vw / 1920, 100vh / 1080)` 计算缩放比例并居中，保证电脑端完整展示 16:9 大屏。
- 当可视区域小于设计画布时，允许页面整体缩放；不修改手机端现有内容与交互逻辑。
- 预留安全边距和最小字号，避免浏览器缩放导致边框、标题和图表挤压。

## 组件与数据表现

1. **Header HUD**：品牌、导航按钮、页面标题、时间、在线状态、返回入口。
2. **KPI Rail**：设备总数、在线率、异常告警、待处理工单，带数值、趋势标识和图形化装饰。
3. **Status Cards**：设备健康状态、运行占比、区域在线率，使用环形图、进度条和状态标签。
4. **Trend Chart**：使用原生 SVG 绘制设备总量与故障量趋势，提供坐标网格、图例、数据高亮点。
5. **Central Focus**：使用 CSS/SVG 组合的设备态势节点、轨道、扫描光和实时数字，承担视觉中心。
6. **Alert Stream**：高优先级告警、处理中工单、今日新增异常，使用色彩、图标和文案同时表达状态。
7. **Ranking / Table**：区域排行进度条和设备告警表，保留可读的表头、状态标签和更新时间。
8. **Bottom Nav**：提供大屏常用导航入口和当前页面选中态。

## 交互与动效

- 顶部导航、返回入口、底部导航为真实可点击元素，保留现有返回总入口链接。
- 页面加载时使用轻量渐入和错峰出现；扫描线、数据点和数字使用低频循环动画。
- hover/focus 状态增强边框与背景亮度，不改变布局尺寸；支持 `prefers-reduced-motion` 关闭装饰动画。
- 时间显示使用客户端实时更新时间，展示当前日期与时分秒。
