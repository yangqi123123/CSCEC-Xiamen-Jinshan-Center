# 产品基座入口页整体布局美化设计

## 目标

在不改变 Web 后台、App 管理端和大屏入口链接的前提下，优化 `index.html` 的首页视觉层次，使其更像统一的企业产品门户：品牌信息清晰、入口优先、页面有稳定的空间节奏，并兼容桌面端和移动端。

## 设计方向

采用“蓝色企业门户 + 运营中枢”方向。保留产品基座现有蓝色主色、低圆角和克制阴影；以深蓝品牌区形成视觉锚点，以三张入口卡片承载主要操作，以底部平台能力信息补充可信度。页面不新增业务数据和交互，只保留入口卡片的 hover/focus 动效与现有跳转。

## 页面结构

1. 顶部品牌栏：产品标记、产品基座名称、统一入口标签和“平台已就绪”状态。
2. 主视觉区：左侧标题、说明和能力标签；右侧用抽象的运营网络装饰强化“统一入口”概念。
3. 入口区：Web 后台、App 管理端、大屏入口三张卡片，Web 作为主入口，其余作为辅助入口；卡片显示图标、定位说明、进入按钮和快捷键式编号。
4. 底部信息栏：统一规范、组件复用、主题适配等平台能力提示。

## 交互与兼容

- 三个入口的 `href` 保持现有值不变。
- 入口卡片支持键盘 focus-visible，hover 只做轻量位移和边框强调。
- 在 980px 以下转为单列，在 720px 以下收紧边距和字号；不产生横向滚动。
- 继续使用现有 Font Awesome CDN 与 `tob-ui.css`，不引入新运行时依赖。

## 验证

- 校验 HTML 中三个入口链接仍存在。
- 使用 Node 对页面内脚本做语法检查；统计 CSS 花括号确保样式块完整。
- 检查响应式规则包含 980px 和 720px 两档。
