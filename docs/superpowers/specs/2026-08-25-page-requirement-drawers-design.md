# 页面需求说明抽屉设计

## 目标

为产品基座所有业务页提供独立、完整的右侧“需求说明”文档。每份文档固定具备需求说明、操作入口、交互动作、数据来源、状态流转、顶部统计卡片说明、输出结果、字段说明八项内容，且不出现模拟数据或通用工作台话术。

## 覆盖范围

工作台、设备台账、个人中心、用户管理、角色管理、菜单管理、部门管理、岗位管理、字典管理、参数设置、通知公告、操作日志和登录日志。

## 架构

在 `app/components/requirement.js` 中集中维护按 `data-menu-key` 索引的独立文档。公共组件优先使用集中配置，遗留页面内 JSON 只作为没有集中配置时的后备。参数设置、通知公告、操作日志、登录日志补充公共组件引用，使每个业务页均能打开需求说明抽屉。

## 内容原则

- 数据来源只描述业务模块及页面间关系，不包含接口地址、模拟数据或 `mock-data.js`。
- 字段说明覆盖筛选区、列表、抽屉新增/编辑/详情中的所有组件；每项独立一行。
- 下拉、单选、多选字段注明枚举来源并列出选项；无状态和无统计卡片的页面明确写“无”。
