# 关键区域监控按钮移除设计

## 目标

从 `Big Screen/weak-electric.html` 的“综合安防 - 关键区域监控”面板中移除“查看系统图”按钮。

## 范围

- 仅修改 `.security-key-video-panel` 的操作区。
- 保留同一操作区中的“全局监控”按钮。
- 保留“监控系统”、道闸系统、门禁系统及其他模块中的“查看系统图”按钮。
- 不修改系统图弹窗、样式、视频网格或其他页面交互。

## 实现

删除目标面板中 `security-system-diagram-trigger` 按钮节点，并检查页面中其他同名按钮仍然存在。若脚本使用通用选择器绑定按钮，继续保留通用逻辑，避免影响其他模块。

## 验收标准

- “关键区域监控”面板只显示“全局监控”操作按钮。
- 页面中其他模块的“查看系统图”按钮不受影响。
- HTML 结构与脚本语法有效，不引入乱码或无关改动。
