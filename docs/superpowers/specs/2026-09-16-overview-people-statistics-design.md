# 总览人员统计周期图表设计

## 目标

在 `Big Screen/overview.html` 的人员统计模块中增加“今日、本周、本月、本年”周期切换，并同时展示人员类型圆环图和通行次数折线图。全部数据使用前端 Mock 数据。

## 界面设计

- 模块标题保持“人员统计”。
- 标题区域下方增加四个周期按钮，默认选中“今日”。
- 周期按钮下方显示“人员类型”小标题；人员类型图保留当前圆环样式和两侧“办公人员、访客”数值，不增加类型图例。
- 圆环区域下方显示“通行次数”小标题及对应折线图，复用报警趋势图的青色曲线、渐变面积、虚线网格和单位样式。
- 今日、本周、本月、本年分别使用小时、星期、日期、月份作为折线图横轴。
- 布局限制在现有人员统计面板内，不改变左右栏结构或其他模块尺寸。

## 交互与数据

- 点击周期按钮后更新按钮选中状态。
- 同一次切换同时更新办公人员、访客、人员总数和通行次数折线图。
- 四个周期分别维护独立 Mock 数据；切换不请求接口。
- SVG 折线图根据数据重绘折线、面积和横轴文字。

## 修改范围

- `Big Screen/overview.html`：人员统计模块结构。
- `Big Screen/styles.css`：人员统计周期按钮、紧凑圆环区域和折线图样式。
- `Big Screen/app.js`：周期 Mock 数据与切换渲染逻辑，仅在总览页初始化。

## 验收标准

- 四个周期按钮可点击且选中状态唯一。
- 每次切换后，圆环数值和折线图同步变化。
- 折线图横轴与所选周期匹配，文字不重叠或溢出。
- “人员类型”和“通行次数”小标题清晰可见，层级一致。
- 原有圆环视觉及“办公人员、访客”两侧布局得到保留。
- 其他页面和总览其他模块不受影响。
