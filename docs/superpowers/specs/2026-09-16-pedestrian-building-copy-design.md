# 人行通行记录楼栋文案调整设计

## 目标

将人行通行记录页面中的楼层式文案统一改为“1号楼”。

## 范围

- 仅修改 `web/pages/monitoring/pedestrian-record.html` 的 Mock 记录。
- 设备名称中的 `34F`、`33F` 前缀替换为“1号楼”，保留后续设备编码。
- 通行位置中的 `3418`、`3302` 整项替换为“1号楼”。
- 不修改大屏或其他页面的楼层选项。

## 验收标准

1. 当前三条 `34F-MK-18` 显示为 `1号楼-MK-18`。
2. 当前三条 `3418` 显示为 `1号楼`。
3. 页面脚本语法正常且无乱码。
