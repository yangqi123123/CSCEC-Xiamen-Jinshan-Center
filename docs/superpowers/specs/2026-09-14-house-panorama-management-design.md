# 房源 360 全景图管理设计

## 目标

将房源新增、编辑抽屉中的“360全景图”文件上传组件替换为“上传全景图”按钮。点击按钮后，在房源管理页面内打开基于设备管理“点位选择”弹窗改造的全景图管理弹窗，支持按楼栋、楼层、房间维护单张全景图。

## 范围

- 仅修改 `web/pages/project/house.html` 及房源管理专属样式。
- 复用设备管理点位选择弹窗的三栏布局、楼层树、平面图素材和弹窗视觉规范。
- 不修改设备管理现有点位选择功能，不抽取或重构设备管理公共组件。
- 使用页面内 Mock 数据和浏览器对象 URL 模拟上传，不接入后端或持久化存储；刷新页面后上传状态重置。

## 交互设计

### 房源抽屉入口

- “360全景图”字段位于“附件”字段上方。
- 原文件上传框改为次级按钮“上传全景图”。
- 按钮旁显示当前房源的上传状态：未上传时显示“未上传”；已上传时显示文件名。
- 新增和编辑抽屉均提供该入口；详情抽屉保持现有信息展示，不额外扩展。

### 全景图管理弹窗

- 使用宽屏居中弹窗，标题为“360全景图管理”，结构为左侧楼层树、中间平面图、右侧房间全景图面板。
- 左侧按楼栋分组展示楼层，默认定位到当前房源所属楼栋和楼层；点击其他楼层后，中间标题和平面图房间区域同步更新。
- 中间复用 `web/assets/images/device-floor-plan.png`，不展示设备点位、设备图例或 X/Y 坐标。
- 平面图上以透明可点击区域表示房间。点击房间后，用主色边框和浅蓝遮罩显示选中状态，并刷新右侧房间信息。
- 弹窗打开时，若当前房源可在当前楼层匹配，则默认选中该房间；否则保持未选择状态。

### 右侧上传面板

- 未选择房间时显示空状态，“上传360全景图”按钮禁用。
- 选择房间后展示楼栋、楼层、房间名称/房号。
- 每个房间仅允许维护一张全景图。
- 未上传时提供“上传360全景图”按钮。
- 已上传时显示图片缩略图、文件名，并提供“预览”“更换”“删除”操作。
- “更换”选择新文件后覆盖当前房间已有文件；“删除”通过系统确认弹窗确认后移除。
- “预览”打开遮罩预览层，图片按容器等比完整展示。

### 文件规则

- 支持 `jpg`、`jpeg`、`png`、`webp`、`bmp`。
- 单次只能选择一个文件。
- 文件类型不符合要求时显示明确提示，不改变原有上传状态。
- 选择成功后立即生成本地预览并更新右侧面板；点击弹窗“确定”后将结果回显到房源抽屉入口。
- 点击“取消”不提交本次弹窗内的新增、更换或删除结果。

## 视觉规范

- 对齐现有设备管理点位弹窗的尺寸、头部、遮罩、三栏间距和底部操作区。
- 使用系统主色 `#135AFA`、2px/4px 圆角、8px 间距体系和 32px 默认按钮高度。
- 左侧楼层树保持可滚动；中间平面图保持完整比例；右侧面板固定宽度，不遮挡主体。
- 窄屏时三栏顺序纵向排列，页面不得出现内容重叠或按钮文字截断。

## 状态模型

- 以“楼栋 / 楼层 / 房间”为键保存全景图 Mock 状态。
- 每条状态包含文件名、对象 URL 和 MIME 类型。
- 弹窗打开时复制当前状态为临时状态；确定时覆盖页面状态，取消时丢弃临时状态。
- 删除或更换对象 URL 时释放不再使用的 URL，避免重复预览占用。

## 验收标准

1. 房源新增、编辑抽屉中的“360全景图”显示为“上传全景图”按钮，不再显示原上传框。
2. 弹窗默认定位当前房源楼栋和楼层，且不展示设备点位、设备图例、X/Y 坐标。
3. 点击平面图房间后，右侧准确展示当前房间及其上传状态。
4. 每个房间只允许一张全景图，并可上传、预览、更换和删除。
5. 取消不保存，确定后房源抽屉正确回显文件名和状态。
6. 文件格式校验、未选房间禁用状态和删除确认均正常。
7. 弹窗在桌面及窄屏下无明显遮挡、重叠或横向溢出。
8. 页面内联脚本通过语法检查，中文内容无乱码，设备管理现有功能不受影响。
