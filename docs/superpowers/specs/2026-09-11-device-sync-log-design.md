# 设备同步与同步日志设计

## 目标

在设备管理页增加设备数据同步、设备状态同步和同步日志能力，并在设备台账中标识数据来源。同步日志与设备列表在同一页面内切换，不新增菜单或独立 HTML 页面。

## 页面模式

页面包含“设备列表”和“同步日志”两种互斥模式：

- 设备列表模式保留现有设备筛选、设备工具栏、列表和分页。
- 点击“同步日志”后，顶部替换为日志筛选区，主体替换为同步日志工具栏、日志列表和分页。
- 日志工具栏提供“刷新批次”和“返回设备列表”。返回后恢复设备列表模式。
- 两种模式分别保留自己的筛选状态，模式切换不修改设备数据。

## 同步设备数据

设备工具栏增加“同步设备数据”按钮，点击后打开右侧抽屉。抽屉字段包括：

- 同步模式：首次全量同步、后续增量同步。
- 同步设备状态：开关，默认关闭。

点击“开始同步”生成模拟批次号并关闭抽屉，随后提示任务已提交。全量同步标记为 `FULL`，增量同步标记为 `INCREMENTAL`；若开启状态同步，则提示中说明设备状态会同步处理。

## 同步设备状态

点击“同步设备状态”直接提交模拟后台任务，显示成功提示、批次号和“任务已在后台执行，可稍后刷新设备列表查看结果”。该操作不阻塞页面，也不立即修改设备记录。

## 同步日志列表

日志筛选字段为批次号、通道编码、同步模式；按钮为重置、搜索。日志列表字段为：

- 批次号
- 通道名称
- 通道编码
- 同步模式
- 批次状态
- 总数
- 成功
- 失败
- 开始时间
- 结束时间
- 操作

批次状态包含执行中、成功、失败，使用系统状态色。操作列显示“查看明细”。刷新批次恢复完整模拟日志数据。

## 批次明细

点击“查看明细”后，在日志列表下方显示当前批次的三个区域：

1. 批次明细：通道、状态、成功/失败、同步模式、开始时间、结束时间和错误信息。
2. 明细筛选：外部设备 ID、外部设备编码、内部设备编码、设备名称，以及重置、搜索。
3. 暂存明细列表：外部设备 ID、外部设备编码、内部设备编码、设备名称、清洗状态、匹配设备 ID、清洗说明、来源更新时间、操作。

明细列表操作为“查看报文”。切换其他批次时更新下方批次信息与明细数据。

## 暂存报文详情

点击“查看报文”打开右侧大抽屉，包含“标准化报文 / 原始报文”页签。报文以等宽字体代码区域展示格式化 JSON，并支持区域内滚动。弹窗只读，不提供编辑和提交操作。

## 来源模块

设备数据增加内部字段 `sourceModule`，选项为“人工台账、第三方同步”：

- 现有及手工新增设备默认为“人工台账”。
- 模拟同步设备使用“第三方同步”。
- 设备列表筛选、列表列、新增、编辑、详情和导出均展示来源模块。
- 导入模板不增加来源模块，导入数据统一视为“人工台账”。
- 来源模块不参与设备层级或下游设备关联判断。

## 验证

- 验证设备列表与同步日志模式双向切换，筛选区和主体内容同步切换。
- 验证两个同步入口的抽屉、提示和批次号。
- 验证日志筛选、重置、刷新、查看明细及报文页签。
- 验证来源模块覆盖筛选、列表、新增、编辑、详情和导出。
- 执行内联 JavaScript 语法检查、HTTP 访问检查和浏览器交互检查。
