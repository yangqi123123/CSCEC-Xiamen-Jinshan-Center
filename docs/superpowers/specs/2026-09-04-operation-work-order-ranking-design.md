# 运营管理工单排行设计

## 目标

在 `Big Screen/operation.html` 的“维保计划”面板下方增加“工单排行”模块，按工单完成人员统计完成数量并展示前五名。

附件图片中的红色标注仅用于说明新增模块的位置和名称，不引入其他页面指令。

## 范围

- 仅修改运营管理左侧“维保计划”区域。
- 新增“工单排行”标题、前五名人员行、完成数量和横向进度条。
- 使用独立的 `workOrderRankingData` 静态工单数据，避免将维保计划记录误作为完整工单数据。
- “本月 / 本年”切换时，排行数据随当前维保计划统计周期刷新。
- 不新增接口、后端逻辑或持久化，不修改右侧运营模块和现有维保弹窗。

## 数据规则

- 排行数据均代表已完成工单，按当前周期分别提供本月和本年统计。
- “本月”使用 `workOrderRankingData.month`， “本年”使用 `workOrderRankingData.year`。
- 按完成数量降序排序；数量相同时按人员名称稳定排序。
- 取排序结果前五名；无数据时展示空状态文案。

## 视觉设计

- 排行标题沿用现有 `.operation-section-title` 斜纹 HUD 样式。
- 每行固定高度，左侧显示圆形序号和人员名称，中间显示青绿色进度条，右侧显示完成数量。
- 第一名使用黄色序号和更亮的进度条，其余名次使用青绿色渐变，保持与维保计划卡片一致。
- 排行列表限制在维保面板内部滚动或裁切范围内，不改变运营大屏固定布局。

## 交互与验收

- 点击“本月”或“本年”后，维保计划和工单排行同步刷新。
- 初始进入运营管理资产管理状态时，排行模块可见并显示本月排行。
- 排行始终最多显示五名，显示姓名和完成数量。
- 1920x1080 基准视口下不遮挡中央建筑、不溢出左侧面板；JavaScript 语法检查通过。
