# 同步设备状态开关设计

## 目标

将设备管理“同步设备数据”抽屉中的“同步设备状态”方形复选框改为系统风格滑动开关。

## 交互

- 默认关闭，开关使用中性灰色，状态文案显示“不同步”。
- 点击后开启，开关使用系统主色蓝，状态文案显示“同步”。
- 再次点击恢复关闭状态。
- 保留现有 `data-sync-with-status` 表单状态和同步任务提交逻辑。

## 样式

- 使用紧凑型滑动开关，尺寸与抽屉表单密度一致。
- 圆形滑块清晰表达开关状态，并提供平滑位移动画。
- 保留键盘聚焦状态和原生复选框语义。

## 范围

只修改 `web/pages/device/list.html` 中该控件的样式与展示，不调整抽屉布局、字段、按钮或同步业务逻辑。

## 验收

- 抽屉中不再显示方形复选框。
- 开关关闭和开启时分别显示“不同步”和“同步”。
- 提交同步任务时仍能读取开关状态。
- 页面无 JavaScript 错误。
