# 中建四局登录页与管理后台品牌升级设计

## 目标

将 Web 登录页与管理后台的“产品基座”品牌统一升级为“中建四局智能运营管理系统”，使用用户提供的中建四局 Logo 和 AI 引导图，并在登录页通过两个 Tab 复用同一登录表单进入可视化大屏或智能运营管理系统。

## 素材与品牌

- 将图一复制到 `web/assets/images`，作为登录页左侧唯一的 AI 引导主图。
- 将图二复制到 `web/assets/images`，作为登录页和管理后台侧栏共用的品牌 Logo。
- 登录页与管理后台可见品牌名称统一为“中建四局智能运营管理系统”。
- 管理后台侧栏宽度保持现状；通过缩小 Logo、文字字号和品牌区间距保证名称完整显示，不截断、不溢出。

## 登录页结构

1. 左侧保留现有标题和说明文案，将原 AI 引导图及四个悬浮标签整体替换为图一。
2. 左上角使用图二 Logo 和新系统名称。
3. 登录卡片顶部增加“可视化大屏”和“智能运营管理系统”两个 Tab，默认选中“智能运营管理系统”。
4. 两个 Tab 共用账号、密码、记住密码和登录按钮；Tab 只决定登录成功后的目标地址。
5. 删除“忘记密码”链接，以及服务协议和隐私政策整行内容。

## 交互

- 点击 Tab 时更新选中态、无障碍状态和当前登录目标，不清空账号或密码。
- 选中“可视化大屏”后点击登录，跳转到 `../Big Screen/overview.html`。
- 选中“智能运营管理系统”后点击登录，跳转到 `pages/home/home.html`。
- 密码显隐按钮继续可用，登录入口继续支持键盘操作。

## 管理后台

- 修改共享侧栏组件，使所有后台页面统一显示图二 Logo 与“中建四局智能运营管理系统”。
- 不修改现有侧栏宽度、菜单层级、展开收起逻辑和页面路由。
- 侧栏收起时仅显示缩小后的 Logo，沿用现有品牌文字隐藏规则。

## 响应式与视觉

- 登录页沿用现有蓝色企业视觉与响应式断点，图片使用等比缩放，不拉伸变形。
- 登录卡片 Tab 使用清晰的蓝色选中态和底部指示线；不新增高圆角或重阴影。
- 在常见桌面宽度及现有窄屏断点下检查品牌名称、Tab、输入框和按钮没有裁切或重叠。

## 验证

- 检查登录页默认 Tab、两种登录目标、Tab 状态切换及密码显隐。
- 检查登录页不再出现“忘记密码”“服务协议”“隐私政策”和旧引导标签。
- 检查后台多个页面均通过共享侧栏显示新 Logo 与完整系统名称。
- 在桌面和窄屏视口进行浏览器截图检查，确认素材渲染、比例、侧栏宽度及文字布局正确。
